Beads board: 3 design directions

Each file is self-contained (open it directly). Every one has Board, Backlog, Decision inbox with option buttons and the clarification thread, project switcher with counts, issue detail, a phone report screen, Arabic RTL and dark mode. Try: Inbox, press the ? beside a part of the question or an option, send, and watch the agent reply on the card.

A. Jira-classic

Familiar, safe, roomy
  • Top bar, tabs, five status columns
  • Project dropdown with counts
  • Detail slides in as a side panel
Open: board · backlog · decisions · report

B. Linear-style

Dense, keyboard-first
  • Sidebar with all projects and counts always visible
  • j/k, Enter, g+key, Cmd/Ctrl+K palette
  • Decisions: press 1-9 to choose, ? to ask
Open: board · backlog · decisions · report
Open B

C. Decisions first

Built for running AI agents
  • Home is what needs you, plus live agent rail
  • Board columns show who holds the next move
  • Backlog by epic with progress
